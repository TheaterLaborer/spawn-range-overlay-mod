## 📖 About

Spawn Range Overlay visualises the hostile mob spawn range around the player, showing the 24-block no-spawn sphere and the 128-block despawn sphere as in-world overlays.

---

## ✨ Features
<a name="features"></a>

- **24-Block Sphere** — no-spawn zone rendered around player.
- **128-Block Sphere** — despawn boundary rendered.
- **Farm Efficiency Zone** — optimal 24-128 block ring highlighted.
- **Y-Level Slice** — 2D cross-section view at current height.
- **Toggle Key** — quick on/off.
- **Color Themes** — adjustable sphere colours.
